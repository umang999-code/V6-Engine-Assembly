# Project Overview

This project is a 3D CAD model and complete assembly of a V6 Internal Combustion Engine, designed and assembled using SolidWorks.

The project demonstrates the arrangement and assembly of major engine components and provides an understanding of the mechanical working of a V6 engine.

# Assembly Procedure

1. Create and prepare the individual engine components.
2. Insert the main cylinder block into the assembly.
3. Position and mate the crankshaft.
4. Assemble the piston and connecting rod mechanisms.
5. Insert the piston assemblies into the cylinders.
6. Add the cylinder heads and valve mechanism.
7. Install the remaining engine components.
8. Apply appropriate mates to define the required motion.
9. Check the complete assembly for interference and proper movement.
10. Complete and verify the final V6 engine assembly.

# Working Principle

A V6 engine is an internal combustion engine with six cylinders arranged in two banks, forming a V-shaped configuration.

During operation, the air-fuel mixture is introduced into the cylinders and ignited. The combustion produces high-pressure gases that push the pistons downward. The connecting rods transfer this reciprocating motion to the crankshaft, which converts it into rotary motion.

The crankshaft transfers this rotational power to the drivetrain through the flywheel and transmission.

The four basic strokes are:

1. Intake – Air-fuel mixture enters the cylinder.
2. Compression – The mixture is compressed by the piston.
3. Power – Combustion pushes the piston downward.
4. Exhaust – Burnt gases are expelled from the cylinder.
